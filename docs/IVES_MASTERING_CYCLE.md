# Campaign voice balance and Ives

This phase evens campaign-wide dialogue levels, revises all thirteen Ives deliveries and adds two expression portraits plus a closer hearing illustration. Authored words, actual actors, ordered quotation keys and earned story outcomes stay aligned.

## Measured playback mastering

The original 290 active deliveries ranged from −24.93 to −16.55 LUFS, an 8.38 dB span. Each exact delivered file is decoded and measured offline with ffmpeg EBU-R128. A constant gain targets −23.5 LUFS before the player’s separate voice-volume bus. The actual post-trim signal is measured again, including corrections for short-phrase gating. The resulting range is **−23.53 to −23.35 LUFS**, a 0.18 dB span; worst measured true peak is **−1.54 dBTP** before the user volume bus. The 70% default voice slider supplies another approximately 3.1 dB attenuation. These are signal measurements, not a claim that every actor has identical perceived timbre or intelligibility.

This target preserves headroom and the original dynamics, breaths and pauses without compression, limiting, re-encoding or duplicated campaign files. `lib/voice-level.ts` reads the small static gain map; `lib/sound.ts` applies it to the clip’s gain node. The voice slider remains independent. The larger measurement manifest stays out of application imports. Music/ambience duck to 22%/44% of their selected volume during speech, about 2 dB quieter than previously, then restore. Existing 120 ms same-actor / 220 ms changed-actor sequence gaps remain. Stop, mute, zero voices, dialogs, departure and pagehide cancel active/pending dialogue; Resume never replays an interrupted queue.

`qa/media/voice-mastering.json` pins every delivery byte hash, original loudness/peak, gain and actually measured post-trim signal. `voice-levels.json` is its hashed runtime map. `scripts/measure-voice-levels.py` is optional offline authoring and must be rerun whenever an active delivery changes; it never runs in game, tests or builds. Future unmeasured ids fall back to unity playback but cannot pass the active-inventory release check.
