# Choice feedback, dialogue and campaign review

This five-stage cycle builds on d3ed65d, whose full CI succeeded and whose Vercel production deployment was confirmed READY before changes began.

1. **Committed consequences.** A reviewable receipt near the next choices lists actual bounded resource, faction and inventory changes, acquired-journal count and any changed objective. Same-scene inspections now receive feedback. Journal additions are records, not assertions of verification. Faction standing is not consent or guaranteed trust. No heat/injury mechanic or hidden-flag interpretation is added. Existing brief numeric header feedback stays available; full detail stays below prose. No timed dismissal or interruption.
2. **Dialogue presentation.** A quiet segmented bar identifies the currently playing recorded line; the transcript also uses an edge marker. A portrait waits for its current image to load, then fades in briefly. Failed images retain the existing placeholder/name. Canonical actor selection, spoken quotation highlights and the existing playback controller own all handoffs, natural completion, manual play, mute, Stop and interruption. No duplicate audio controller or delayed voice start.
3. **Location arrival.** A decorative 240ms heading accent restarts when the actual location/act changes. Portrait arrival is 160ms. Neither controls story visibility, navigation, focus, scrolling or choice availability. Both saved and OS reduced motion disable them. There is no extra scene interstitial or screen-covering fade.
4. **Save and return.** Title details and occupied manual slots share a native expandable recap: saved chapter/location, the last three chosen labels in chronological order, and a clear reminder when a die remains held. The labels are explicitly actions, not inferred outcomes. Empty legacy histories remain valid. Existing goal, autosave warnings, replacement confirmation and save schema are preserved. Expanding a recap neither loads nor changes the run.
5. **Campaign validation.** Source, production and browser checks cover campaign state, voice/text/actor matching, silent/text-only operation, missing assets, narrow layouts, finales, recovery and held results. Detailed results are recorded below after verification.
