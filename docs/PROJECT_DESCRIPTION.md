# Saint Shard — project description

## Short repository description

Saint Shard: a solo cyberpunk story RPG set in Kite City, 3055. Branching choices, 1d10 checks, illustrated scenes, voiced dialogue and local saves. Built with Next.js and React.

## Game overview

Take a memory-retrieval job that draws you into Ward Nine’s history and the lives of its surviving witnesses. Build a runner around Chrome, Nerve, Face or Ghost, weigh the costs of each approach, and choose what to do with the evidence you uncover. The campaign spans The Hour, The Week and The Wall, with four original finales.

Illustrated locations and character portraits accompany fixed voiced dialogue. A field guide introduces the setting and rules; reading, sound, artwork and accessibility settings let players adjust the presentation. Progress stays in the browser, with manual save slots and export/import. Play requires no account.

The latest [visual library cycle](VISUAL_LIBRARY_CYCLE.md) adds compact actor strips beside character paintings, illustrated owned equipment, two more earned scene variants, and an accessible zoomable artwork viewer. Opening a painting interrupts dialogue safely and returns focus when closed. Artwork remains optional.

- Witness transport, approved recording and public quotation permission keep separate outcomes.
