# Earned character profiles

The People list now gives all fifteen encountered characters an **About** disclosure with a larger neutral portrait and a short first-encounter introduction. Names, roles and existing shared history stay visible on the compact card. An optional **Encounter notes** disclosure collects relevant entries already in the saved journal, preserving their exact authored text, fact/claim/promise kind and live promise status. It adds no omniscient history or speculative relationship score.

## Discovery and source limits

Profiles use the same encounter gate as People: saved encounters, supported legacy facts, the current main speaker and actually revealed attributed supporting dialogue. Partial paragraph reading cannot reveal a supporting character early. First-encounter introductions contain only that person's public identity. Personal hopes, company, employment outcomes, refusals, receipts and contact boundaries appear only when their existing journal entry was earned. A legacy outcome flag cannot create a missing entry. Some supporting characters have only an introduction until relevant notes are recorded; no extra private biography is invented to fill a card.
