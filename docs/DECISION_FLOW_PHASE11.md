## What changed

The workshop previously put four full kit comparisons, their review links and repeated descriptions before all four purchase buttons. Each purchase now sits inside its own kit card, after its actual price, remaining-cash comparison and existing read-only review link. The original canonical renderer supplies that button exactly once, retaining its id, original number/shortcut, label, details, availability, effects and commit handler. The four purchases and the existing return remain in canonical order. Only explicitly listed field kits are moved; an unrelated future `buy-` action is not silently discarded.

Each enabled purchase displays its complete original scope at the former catalog's body-text size and line height. The duplicate uses remain available inside the existing odds reference. Unaffordable or unavailable purchases retain the full comparison text and actual disabled reason. The repeated explanation of review links appears once before the cards, while the original care/rest/courier benchmarks and no-evidence/no-room/no-consent terms stay visible before purchasing. These are comparisons, never reserved money or successful care.

**Review leaving without buying** is a read-only link to the existing return choice. It changes no save, money, item, log, consent or outcome. Players can still scroll or use the original shortcut to select the canonical return directly; finding it adds no compulsory confirmation. Both purchase-review links and this return link measure the actual sticky header, focus without an automatic competing scroll, then position the target label below the header. Changing text size during the scene remains supported.

In the other selected workspaces, saved commitments, the recent-choice receipt and full action-reference instructions follow the decisions. The existing campaign-thread control stays before them to retain the fixed review policy's keyboard behavior. Active record comparisons, complete source/permission rows, route plans, costs and trace warnings remain before their decisions. Every disabled reason stays on its actual button. A short immediate-commit reminder remains above actions; complete check/Back instructions and marker/reference information remain available below.

The archive retains each inspected description in full. While inspection is incomplete, individual inspected labels remain; after all three are read, the existing shared **3 of 3 descriptions inspected** status replaces three repeated labels. It grants no retrieval or authentication. The testimony overview keeps native `dt`/`dd` source pairs and their exact written values, laid out inline within each row rather than adding a separate line for every heading. Spacing and nested frames are reduced without smaller source text or smaller touch targets.
